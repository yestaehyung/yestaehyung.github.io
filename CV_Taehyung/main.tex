\resumeProject
  {TRIPLE (AAAI)}
  {First Author}
  {}
  {2025}

\resumeItemListStart
  \item TRIPLE (Theory-guided Reasoning for Intent and habIt Profiling with LLMs for pErsonalization) is a novel framework that integrates dual-process theory and the Theory of Planned Behavior (TPB) into LLM-based user modeling.
  \item Constructs both habitual and intentional behavior profiles, then generates behavioral rationale that explains the interaction between these processes to predict user behavior.
\resumeItemListEnd

\resumeProject
  {TRIPLE (CIKM)}
  {First Author}
  {}
  {2025}

\resumeItemListStart
  \item TRIPLE is a profiling technology that combines the Theory of Planned Behavior (TPB) with Large Language Models (LLMs).
  \item Uses LLMs to understand a user's psychological motivations and refines their profile by comparing predictions with actual behavior, dramatically improving personalization services.
\resumeItemListEnd

\resumeProject
  {Red Teaming Attack Dataset Analysis}
  {Project Leader}
  {}
  {2024}

\resumeItemListStart
  \item Analyzed real-world LLM vulnerabilities using attack data from the 2023 DEF CON 31 Generative AI Red Teaming Challenge.
  \item Preprocessed and relabeled the dataset to identify which target categories are most susceptible to harmful-content attacks.
  \item Classified victim groups and categorized prompt types to reveal systematic patterns in successful jailbreaks.
\resumeItemListEnd

\resumeProject
  {Multi-Agent Personality Detection System (PADO)}
  {Second Author}
  {}
  {2024}

\resumeItemListStart
  \item PADO is a multi-agent system that detects personality traits (OCEAN) from user-generated text.
  \item Multiple specialized agents collaborate to perform more accurate personality analysis.
\resumeItemListEnd

\resumeProject
  {Fashion-FINE}
  {Third Author}
  {}
  {2024}

\resumeItemListStart
  \item Fashion-FINE is a Vision-Language Pre-training model for fine-grained fashion retrieval.
  \item Introduces modality-agnostic adapter, hard negative mining with focal loss, and comprehensive cross-modal alignment.
\resumeItemListEnd

\resumeProject
  {My Own Style (MOS)}
  {First Author}
  {}
  {May. 2022 - Present}

\resumeItemListStart
  \item Investigated how domain expertise shapes user perception and satisfaction with fashion-recommendation outcomes.
  \item Built MOS dashboard that analyzes outfit images and recommends similar/diverse fashion items.
  \item Large-scale study with 166 participants showing fashion experts prefer highly similar recommendations while non-experts prefer diverse results.
