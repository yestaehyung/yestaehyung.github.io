PADO: Personality-induced multi-Agents for Detecting OCEAN in human-generated texts

Haein Yeo1, Taehyung Noh1, Seungwan Jin1, Kyungsik Han1,*
1Hanyang University *Corresponding Author
Paper Code (Coming Soon)

Abstract

Detecting personality traits from text is a long-standing challenge in computational psycholinguistics. Most existing approaches treat personality as a flat multi-label task, ignoring that the Big Five (OCEAN) traits are conceptually distinct and require different linguistic evidence. We introduce PADO (Personality-induced multi-Agents for Detecting OCEAN), a multi-agent framework where each agent is specialized for a single personality dimension. Specialized agents independently analyze input text through trait-specific lenses, and a coordinator agent synthesizes their outputs into a final personality profile. Across benchmark datasets and multiple LLM backbones, PADO yields more accurate and interpretable trait predictions than single-prompt baselines, especially on traits whose linguistic markers are subtle or context-dependent.

Framework Overview

PADO decomposes personality detection into five trait-specialized analyses run in parallel, then aggregates them through a coordinator agent. This decomposition mirrors the conceptual structure of the OCEAN model and lets each agent focus on dimension-specific cues without having to balance all five traits at once.

Figure 1: PADO multi-agent framework. Five trait-specialized agents analyze the input text in parallel; a coordinator agent synthesizes the OCEAN profile.

Five Trait-Specialized Agents

O · Openness

Openness Agent

Reads for curiosity, abstract reasoning, novelty-seeking vocabulary, and aesthetic engagement. Distinguishes explorative phrasing from routine descriptive language.

C · Conscientiousness

Conscientiousness Agent

Looks for goal orientation, planning, reliability cues, and self-discipline markers. Captures structure in how the writer organizes time, tasks, and obligations.

E · Extraversion

Extraversion Agent

Detects social engagement, energy, assertive tone, and orientation toward others. Differentiates outward-facing narratives from introspective ones.

A · Agreeableness

Agreeableness Agent

Identifies warmth, cooperative framing, empathy expressions, and prosocial reasoning. Separates genuine care signals from polite formulaic phrases.

N · Neuroticism

Neuroticism Agent

Picks up emotional reactivity, anxiety markers, vulnerability disclosures, and stress framing. Calibrates against context to avoid mistaking situational venting for trait-level neuroticism.

Coordinator Agent

Synthesis

Coordinator Agent

Receives the trait-level outputs and consolidates them into a coherent OCEAN profile. Resolves conflicts when agents disagree, weights evidence by confidence, and produces the final structured prediction together with a short rationale.
