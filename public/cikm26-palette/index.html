From Preferences to Values: Evaluating Latent User Understanding and Transfer in LLMs

Taehyung Noh1, Haein Yeo1, Beejin Son1, Kyungsik Han1,*
1Hanyang University *Corresponding Author
Dataset

PALETTE evaluates whether LLMs can infer a user's hidden value and situational preference from implicit behavioral cues during an ongoing dialogue (Task 1: Dialogue-Based Understanding), and subsequently apply this inferred understanding to generate appropriate responses in a topically distinct new context (Task 2: New-Context Application).

Abstract

Personalized LLM agents should adapt to users who often reveal preferences through behavioral cues rather than explicit statements. Because existing benchmarks mainly evaluate surface-level profile matching, we propose PALETTE, a theory-driven benchmark designed to evaluate value-based user understanding in LLMs. Grounded in Schwartz's ten basic values, PALETTE contains 25,200 dialogues across 400 personas, pairing a historical dialogue that reveals a situational preference with a new context request that necessitates the same underlying value. We evaluate models on Dialogue-Based Understanding and New-Context Application to examine whether they can infer latent values from behavioral signals and generalize them across contexts. Our experiments with seven LLMs demonstrate that while models generate contextually appropriate dialog responses, they struggle to project an understanding of hidden values onto new contexts. PALETTE thus provides a diagnostic framework for verifying whether personalized agents can move beyond mere preference matching toward genuine, value-based user understanding.

Key Contributions

  • We redefine the personalization problem by distinguishing surface-level situational preferences from trans-situational latent values, introducing the concept of value transfer to the LLM evaluation literature.
  • We develop a rigorously decoupled dataset of 25,200 dialogues grounded in social science theory to benchmark value-driven user understanding without shortcut exploitation.
  • We conduct a comprehensive audit of multiple LLMs, revealing a critical gap between conversational appropriateness and latent value comprehension, offering actionable directions for future personalized agent architectures.

Task Formulation

Each PALETTE scenario is formulated as ⟨p, v*, π*, s, h⟩: user persona p, latent value v*, situational preference π*, original setting s, and new context h. We evaluate via two sequential tasks:

Task 1: Dialogue-Based Understanding

The model interacts with a user agent in s, whose preferences are conveyed implicitly through behavioral cues. At each turn, the model generates a user-visible response and a hidden user-understanding prediction (inferring π* and v*). Separating v* and π* in this hidden prediction ensures we evaluate whether models infer the underlying value motivating a preference, rather than just recognizing the preference itself.

Task 2: New-Context Application

The model receives the s dialogue history and the new context h to generate a single-turn response and an updated inference. Because s and h are intentionally designed to be lexically and topically distinct, this task strictly assesses whether the model can adapt the inferred value to new situations without relying on surface matching.

Experiment Results

In Dialogue-Based Understanding, RA consistently exceeds UA—reaching 70% for RA compared to 49% for UA—suggesting that models can generate superficially appropriate dialogue responses without accurately inferring the user's latent values. In New-Context Application, response appropriateness drops by up to 25.1 percentage points when models are transitioned into decoupled domains, exposing a critical vulnerability in current agent alignment paradigms.

Key Finding

While modern LLMs are remarkably adept at maintaining conversational fluency and surface appropriateness, they struggle with true latent inference and cross-context value transfer. In particular, response appropriateness drops by up to 25.1% points when models are transitioned into decoupled domains, exposing a critical vulnerability in current agent alignment paradigms.
