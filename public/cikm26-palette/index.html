CIKM 2026 · Short Paper

Language models can match a user's preferences without understanding the values behind them

Taehyung Noh, Haein Yeo, Beejin Son, Kyungsik Han

Hanyang University

Users often show what they want through behavior rather than saying it. PALETTE is a benchmark of 25,200 dialogues across 400 personas that tests whether an LLM can infer the value behind a user's preference, and then carry that value into a new, unrelated context.

01 / The problem

Personalized LLM agents are supposed to adapt to the people they serve. Yet users often reveal what they want through behavioral cues rather than explicit statements, and existing benchmarks mostly check surface-level profile matching: does the response fit the stated preference?

Preferences are not values. A preference is situational: it belongs to one setting. A value is trans-situational: it is the reason behind the preference, and it should still apply when the topic changes. An agent that only learns the preference can look personal in the conversation it saw and fail in the next one.

Value transfer. PALETTE reframes personalization around this distinction. It asks whether a model can infer a user's latent value from implicit cues and then apply it in a new context, which the paper calls value transfer.

02 / How PALETTE works

PALETTE is grounded in Schwartz's ten basic human values. Each scenario is a tuple ⟨p, v*, π*, s, h⟩: a user persona p, a latent value v*, a situational preference π*, an original setting s, and a new context h. Models are evaluated on two tasks in sequence.

Task 1: Dialogue-Based Understanding. The model talks with a user agent in setting s. The user's preference is conveyed only through behavioral cues. At each turn the model writes a visible reply and a hidden prediction of both π* and v*. Asking for the two separately shows whether the model grasps the underlying value that motivates a preference, not just the preference itself.

Task 2: New-Context Application. The model receives the dialogue history from s and the new context h, and produces a single-turn reply and an updated inference. Settings s and h are designed to be lexically and topically distinct, so the model cannot succeed by surface matching.

Two scores. Each task reports Understanding Accuracy (UA), for the hidden inference, and Response Appropriateness (RA), for the reply. RA−UA measures how far a model's replies run ahead of its understanding within a task. ΔRA, new-context RA minus dialogue RA, measures how much appropriateness survives the change of context.

The dataset. 400 personas, each assigned 3 Schwartz values, give 1,200 persona–value scenarios. Each of the seven target LLMs produced 3,600 dialogue records, 25,200 in total. The full set is released on figshare. The dataset is built to decouple the two settings, so models cannot exploit shortcuts.

03 / What we found

Fluent replies, shallow inference. In Dialogue-Based Understanding, RA exceeded UA for every model, reaching 70% for RA against 49% for UA. Models can produce replies that seem appropriate without correctly inferring the value that drives the user.

Appropriateness does not transfer. When the same models moved to the new context, response appropriateness fell for all seven, by up to 25.1 percentage points (FIG. 01). DeepSeek-V3.1 held up best, losing 2.9 points, and also had the highest UA in both tasks.

What this means. Today's LLMs are good at conversational fluency and surface appropriateness, but they struggle with latent inference and with carrying a value across contexts. The paper reads this as a critical weakness in how current agents are aligned to users, and offers PALETTE as a diagnostic for whether a personalized agent has moved beyond preference matching toward value-based understanding.
